First-Time Setup Steps

  1. Rotate and copy tenant redeem key from Owner panel for the exact slug.
  2. Open MixItUp Desktop and create/open your Bingo Card reward command.
  3. Add a Web Request action and paste the matching tenant block.
  4. Replace only the Bearer key placeholder. Contact Bingo Owner For Secret Key if you do not have it.
  5. Add the Chat Message action values from this sheet.
  6. Start a round in Bingo Control for the same tenant.
  7. Redeem once and verify a viewer URL is delivered.

Quick Troubleshooting

  • join_not_available: No active round is open/running for that tenant.
  • invalid_tenant_redeem_auth / invalid_internal_secret: Key is missing, wrong, or from another tenant.
  • redeem_id_conflict: Same redemptionId reused with a different twitchUserId.
  • Redeems fail after key rotation: Update MixItUp with newest key immediately.
  • Viewer says invite token missing: Open the full viewerUrl returned by the API response.

Tip: If slug mapping is wrong, redeem may hit the wrong tenant context or fail unexpectedly. Verify Broadcaster -> Slug mapping in Owner panel Tenant Overview.
